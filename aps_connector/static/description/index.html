APS Connector

Finite Capacity Scheduling for Odoo Manufacturing

Odoo schedules manufacturing orders without checking if a work center is already booked. It doesn't follow subassembly dependencies across MOs. And it picks alternative work centers by earliest start, not earliest finish.

APS 4 Manufacturing fixes all three. This free connector module syncs your manufacturing data to APS, which schedules against real work center capacity, shift calendars, and cross-MO dependencies — then writes optimized dates back to Odoo automatically.

What APS Does

▶ Finite Capacity Scheduling

Schedules work orders against real work center capacity and shift calendars. No more double-booking machines or scheduling over non-working hours.

▶ Cross-MO Dependencies

Subassemblies are always scheduled before their parent manufacturing orders. No more starting a job before its components are ready.

▶ What-If Scenarios

Copy your dataset, change priorities or capacity, reschedule, and compare results side by side before committing anything back to Odoo.

▶ Interactive Gantt Chart

Visual production schedule across all work centers. Drag and drop operations to reschedule. See bottlenecks at a glance.

▶ Material Re-Reservation

After rescheduling, materials are automatically re-allocated based on the new production sequence and priorities.

▶ Automatic Sync

Syncs every 15 minutes. Supports incremental sync — only changed records are transferred, keeping it fast even with thousands of work orders.

How the Connector Works

▶ Bulk Data Export

High-performance SQL-based endpoints export manufacturing orders, work orders, BOMs, resources, calendars, and materials in a single call.

▶ Schedule Write-Back

Pushes optimized start/end dates from APS back to Odoo work orders. Includes validation to prevent writing to completed or cancelled orders.

▶ Secure API Authentication

API keys are stored as SHA-256 hashes. Rate limiting protects against brute force. All access is logged for audit purposes.

▶ Multi-Company Support

All endpoints filter by the API key's company, ensuring complete data isolation in multi-company Odoo environments.

Setup in 3 Steps

  1. Install this module from the Odoo Apps menu
  2. Go to Manufacturing > Configuration > APS Settings and generate an API key
  3. Sign up at aps4mfg.com, enter your Odoo URL and API key, and run your first sync
