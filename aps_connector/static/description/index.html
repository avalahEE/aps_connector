APS Connector

Connect Odoo to APS 4 Odoo for Advanced Planning & Scheduling

This free connector module bridges your Odoo manufacturing data with APS 4 Odoo, an external Advanced Planning & Scheduling system built specifically for Odoo. It provides secure, read-only API endpoints that export your manufacturing data in the format APS needs, plus a write-back endpoint to push optimized schedules back into Odoo work orders.

Key Features

▶ Bulk Data Export

High-performance SQL-based endpoints export manufacturing orders, work orders, BOMs, resources, calendars, and materials in a single call.

▶ Schedule Write-Back

Push optimized start/end dates from APS back to Odoo work orders. Includes validation to prevent writing to completed or cancelled orders.

▶ Maintenance Integration

Export blocking maintenance requests so APS can schedule around planned downtime. Automatically detects if the maintenance module is installed.

▶ Multi-Company Support

All endpoints filter by the API key's company, ensuring complete data isolation in multi-company Odoo environments.

▶ Secure API Key Authentication

API keys are stored as SHA-256 hashes. Rate limiting protects against brute force. All access is logged for audit purposes.

▶ Incremental Sync

Supports both full and incremental sync modes. Only changed records are transferred, keeping sync fast even with large datasets.

Configuration

  1. Install this module from the Odoo Apps menu
  2. Go to Manufacturing > Configuration > APS Settings
  3. Enter your APS server URL and generate an API key
  4. The APS system will use this key to securely read your manufacturing data
